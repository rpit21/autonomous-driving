# autonomous-driving

## Requeriments

### Virtual enviroment

Create:

```bash
python -m venv .venv
```
Activate:

```bash
.venv\Scripts\activate
```

Install libraries:

```bash
python -m pip install --upgrade pip
pip install torch torchvision torchaudio
pip install transformers timm
pip install numpy matplotlib tqdm
pip install opencv-python
```
